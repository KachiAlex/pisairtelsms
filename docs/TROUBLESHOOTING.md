## Quick Troubleshooting

### Issue: Can't Log In

**Symptoms**: Login fails with error message

**Solutions**:
1. Verify email and password are correct
2. Check Caps Lock is off
3. Try resetting password (Forgot Password link)
4. Clear browser cache and cookies
5. Try a different browser
6. Check internet connection
7. Contact support if issue persists

**Error Messages**:
- "Invalid email or password" → Check credentials
- "Account locked" → Contact support
- "Too many login attempts" → Wait 15 minutes and try again

---

### Issue: Forgot Password

**Symptoms**: Can't remember password

**Solutions**:
1. Click "Forgot Password?" on login page
2. Enter your email address
3. Check email for reset link (check spam folder)
4. Click link and create new password
5. Log in with new password

**If you don't receive email**:
1. Check spam/junk folder
2. Wait 5 minutes and try again
3. Verify email address is correct
4. Contact support

---

### Issue: Can't See Child's Data

**Symptoms**: Dashboard shows no data or wrong child's data

**Solutions**:
1. Verify correct child is selected in dropdown
2. Check child is linked to your account (Profile → Children)
3. Refresh the page (F5 or Ctrl+R)
4. Log out and log back in
5. Clear browser cache
6. Try a different browser
7. Contact support

**Possible Causes**:
- Child not linked to account
- Child account not activated
- Data not yet synced
- Browser cache issue

---

### Issue: Portal Loading Slowly

**Symptoms**: Pages take a long time to load

**Solutions**:
1. Check internet connection speed
2. Close other browser tabs
3. Refresh the page
4. Clear browser cache
5. Disable browser extensions
6. Try a different browser
7. Try a different device
8. Contact support if issue persists

**Performance Tips**:
- Use a modern browser (Chrome, Firefox, Safari, Edge)
- Close unnecessary browser tabs
- Disable ad blockers (they can slow things down)
- Use a wired connection if possible
- Restart your device

---

### Issue: Not Receiving Notifications

**Symptoms**: Not getting email or SMS notifications

**Solutions**:
1. Check notification preferences (Notifications → Preferences)
2. Verify notifications are enabled for the type you want
3. Check email address is correct (Profile)
4. Check phone number is correct (Profile)
5. Check spam/junk folder for emails
6. Check SMS settings with your phone provider
7. Contact support

**Notification Preferences**:
- Go to Notifications → Preferences
- Enable/disable by notification type
- Enable/disable by channel (email, SMS, in-app)
- Save changes

## Network Issues

### Problem: No Internet Connection

**Symptoms**: Can't access portal at all

**Solutions**:
1. Check WiFi or mobile connection
2. Restart router/modem
3. Try a different network
4. Check with your ISP
5. Try mobile hotspot

### Problem: Slow Internet

**Symptoms**: Portal loads very slowly

**Solutions**:
1. Check internet speed (speedtest.net)
2. Restart router/modem
3. Move closer to router
4. Reduce number of connected devices
5. Contact ISP if speed is consistently slow

### Problem: Connection Drops

**Symptoms**: Portal disconnects or times out

**Solutions**:
1. Check WiFi signal strength
2. Restart router/modem
3. Move closer to router
4. Try a wired connection
5. Contact ISP

## Security Issues

### Problem: Account Compromised

**Symptoms**: Unauthorized access or suspicious activity

**Solutions**:
1. Change password immediately
2. Log out all sessions
3. Contact support
4. Monitor account for suspicious activity
5. Enable two-factor authentication (if available)

### Problem: Suspicious Email

**Symptoms**: Received suspicious email claiming to be from portal

**Solutions**:
1. Do NOT click links in suspicious emails
2. Do NOT enter credentials
3. Report email as phishing
4. Contact support
5. Change password if you clicked a link

### Problem: Forgot to Log Out

**Symptoms**: Left portal logged in on shared device

**Solutions**:
1. Log in from another device
2. Go to Profile → Security
3. Click "Log Out All Sessions"
4. Change password
5. Log back in

## Error Messages

### Common Error Messages

| Error | Meaning | Solution |
|-------|---------|----------|
| 401 Unauthorized | Not logged in or token expired | Log in again |
| 403 Forbidden | Don't have permission | Contact admin |
| 404 Not Found | Resource doesn't exist | Verify URL or ID |
| 500 Server Error | Server problem | Try again later, contact support |
| Network Error | Connection problem | Check internet, try again |
| Timeout | Request took too long | Try again, check internet |

### How to Report an Error

1. Note the exact error message
2. Note the time it occurred
3. Note what you were trying to do
4. Note your browser and device
5. Contact support with this information

## Frequently Encountered Issues

### Issue: "Child not linked to parent"

**Cause**: Child is not linked to your account

**Solution**:
1. Go to Profile → Linked Children
2. Verify child is listed
3. If not listed, click "Add Child"
4. Enter child's verification code
5. Click "Link Child"

### Issue: "Invalid token"

**Cause**: Session expired or token invalid

**Solution**:
1. Log out
2. Log back in
3. Try a different browser
4. Clear browser cache

### Issue: "Rate limit exceeded"

**Cause**: Too many requests in short time

**Solution**:
1. Wait a few minutes
2. Try again
3. Avoid rapid clicking/refreshing

### Issue: "Database connection error"

**Cause**: Server database issue

**Solution**:
1. Try again in a few minutes
2. Contact support if persists
